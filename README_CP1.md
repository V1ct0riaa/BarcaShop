# Jelaskan peran settings.py dalam proyek Django!
## Jawab
Settings.py pada proyek django berguna sebagai konfigurasi yang akan digunakan oleh proyek. Hal-hal seperti menyambungkan aplikasi, host mana yang boleh mengakses aplikasi, hingga konfigurasi deployment dan juga database.

# Bagaimana cara kerja migrasi database di Django?
## Jawab
Cara kerja migrasi database di Django adalah proses perubahan `migrate` yang harus dilakukan setiap kali ada perubahan pada Models aplikasi. Migrasi model ini dilakukan agar Django bisa track perubahan model pada database. Migrasi sendiri adalah instruksi untuk mengubah table database sesuai dengan perubahan Models yang di-define.
